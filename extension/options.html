Work Tracker

Clock in, break and clock out from the toolbar.

1. Connect your workspace

In Supabase, open Project Settings → API and copy the Project URL and the publishable key (sb_publishable_…, or the older anon public key). Paste both here and click Save & test.

2. Sign in

Open the extension from the toolbar and sign in with the email and password your administrator created for you. The session is remembered, so you only do this once.

About

  • Clock in, start/end a break and clock out — nothing else, and no time tracking outside a shift.
  • Punches are written straight to the same Supabase tables as the web app. Your administrator sees them live in the dashboard, Time Entries and Reports, and gets the usual clock-in / break / clock-out notifications.
  • Hours are counted server-side from the clock-in timestamp, so closing the popup never loses time.

Never paste the service-role key here. It bypasses Row Level Security. Only the publishable (anon) key belongs in a browser extension.
